# AI Project 2 - Data Classification Using AI

## Project Overview

This project builds a machine learning classification model using the Iris dataset and K-Nearest Neighbors (KNN) algorithm.

The model is trained using supervised learning techniques and evaluated using accuracy score, confusion matrix, and classification report.

## Technologies Used

- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

## Dataset

The Iris dataset contains:

- 150 samples
- 4 input features
- 3 flower classes

## Algorithm Used

K-Nearest Neighbors (KNN)

## Project Workflow

1. Load Iris dataset
2. Split dataset into training and testing data
3. Apply feature scaling
4. Train KNN model
5. Predict test data
6. Evaluate model performance
7. Display confusion matrix

## Output

- Accuracy Score
- Confusion Matrix
- Classification Report

## Run Project

Install required libraries:

pip install -r requirements.txt

Run the project:

python main.py

## Conclusion

This project demonstrates the basic workflow of supervised machine learning classification using Python and Scikit-learn.
